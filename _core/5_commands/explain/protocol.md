**Process**
1. **Purpose** — What this code does and why it exists.
2. **Architecture** — How it fits into the broader system (dependencies, callers, data flow).
3. **Key Logic** — Walk through the critical code paths and algorithms.
4. **Design Decisions** — Identify patterns used and explain why they were chosen.
5. **Potential Concerns** — Flag any code smells, missing error handling, or unclear sections.
