## Process

1. Read and understand the changes and their intent.
2. Check correctness, security, performance, types, and quality.
3. Categorize findings by severity (Critical / Warning / Suggestion) with file:line references.
4. If security concerns are found, delegate to the security-reviewer.
5. End with a verdict: Approved / Approved with suggestions / Changes requested.
