# Research

Disciplined research against primary sources.

## Source Discipline

Prefer in this order: official docs → source code → specs → first-party APIs. Secondary sources (blog posts, tutorials, AI-generated summaries) may be noted but never used as sole evidence. Follow every claim back to the source that owns it.

## Citation

Every factual claim cites its source:

- URL for web docs
- File path + line number for code
- Section/paragraph for specs

Un-cited claims are speculation — mark them clearly or remove them.

## Output

Write findings to a single Markdown file saved where the repo keeps such notes. Match existing conventions; if none exist, state where you put it.

Structure:
- **Question** — what was asked
- **Findings** — answers with citations
- **Sources** — consolidated list of all cited sources
